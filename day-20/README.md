## System Message — правила цитирования
В конце каждого ответа указывай источник:

SQL Tool → "📚 Источник: SQL Tool (база из 40 вопросов)"

Python Tool → "📚 Источник: Python Tool (база из 40 вопросов)"

Search with Cache → "🌐 Источник: [сайт] ([URL])"


## Зачем это нужно
1. **Доверие** — пользователь видит, откуда информация
2. **Проверяемость** — можно перейти по ссылке и убедиться
3. **Прозрачность** — бот не «чёрный ящик»
4. **Production-подход** — так работают реальные AI-ассистенты

## Примеры ответов
**SQL:**
"JOIN — это операция в SQL... Виды: INNER, LEFT, RIGHT, FULL, CROSS.
📚 Источник: SQL Tool (база из 40 вопросов)"

**Интернет:**
"Rust — это системный язык программирования от Mozilla...
🌐 Источник: Wikipedia (https://ru.wikipedia.org/wiki/Rust)"
