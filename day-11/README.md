## Context Window Length — что это
Сколько последних сообщений агент передаёт в модель при каждом запросе.

| Значение | Плюсы | Минусы |
|----------|-------|--------|
| **3** | Минимум токенов | Забывает контекст |
| **5** | Оптимум | Хватает для диалога |
| **10** | Помнит много | Много токенов |
| **20** | Длинный контекст | Упирается в TPM |

## Оптимизация
- **Context Window Length = 5** — 2-3 пары «вопрос-ответ», хватает для диалога
- **Groq лимит:** 8000 TPM на `openai/gpt-oss-20b`
- **Совет:** при превышении TPM — снизить Context Window Length или Limit в Tools
