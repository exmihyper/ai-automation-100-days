## Что даёт Evaluation
1. **Объективность** — не «мне кажется, стало лучше», а конкретные цифры
2. **Воспроизводимость** — можно запускать после каждого изменения
3. **Сравнение** — можно сравнить модели, промпты, версии RAG
4. **Production-подход** — так работают в реальных компаниях
